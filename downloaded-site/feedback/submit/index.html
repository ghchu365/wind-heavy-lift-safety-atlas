字段说明

建议内容 ​

填写要求

  1. 建议类型：请选择最合适的类型
  2. 建议标题：简洁明了地概括您的建议
  3. 详细描述：请详细描述您的建议或意见
  4. 附件上传：可上传相关文档或图片作为参考

提交说明 ​

温馨提示

  1. 带 * 号的字段为必填项
  2. 附件支持图片(png/jpg)和文档(pdf/word)格式
  3. 单个附件大小不超过10MB
  4. 我们将在3个工作日内回复您的建议

建议处理流程 ​

提交建议 → 审核评估 → 处理回复 → 采纳改进 → 致谢反馈
